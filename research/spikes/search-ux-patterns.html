Design Notes

UX Research Findings (via Baymard MCP)

Key Improvements Based on Best Practices:

  • Query Display: Shows what was searched to confirm the query was applied
  • Result Count Badge: Purple badge with count provides clear feedback on search scope
  • Visual Treatment: Purple accent bar + subtle background creates clear "results context" zone
  • Accessibility: role="status" with aria-live="polite" announces results to screen readers
  • Null State Tone: Practical and encouraging, not playful. Clear next steps.
  • Empty State Actions: Primary CTA to browse all + secondary to clear search

Elevate Design System Compliance:

  • Typography: Label Sm (14px/600) for badge, Body (16px/400) for query text
  • Colors: Purple-100 (#5746b2) for brand elements, neutral scale for text
  • Spacing: All spacing is multiple of 4px (space-4, space-5, space-6)
  • Radius: radius-pill-md (24px) for badge, radius-sm (8px) for containers
  • Empty state follows DESIGN.md guidance: "explain, reassure, and offer next step"

## 📐 File Organization Conventions

### Naming for Future Screenshots

When adding screenshots to this directory:

```
[element]-[view]-YYYY-MM-DD.png

Examples:
- pricing-page-2026-04-10.png
- dashboard-main-2026-04-10.png
- dashboard-credits-balance-2026-04-10.png
- subscription-settings-2026-04-10.png
- usage-analytics-breakdown-2026-04-10.png
- checkout-step1-plan-selection-2026-04-10.png
- mobile-ios-credit-display-2026-04-10.png
```

### Metadata for Screenshots

Include in README.md or companion .txt:
- **Date captured**
- **Account tier** (free/starter/creator/etc.)
- **Source** (web/iOS/android)
- **Context** (what action triggered this)
- **Notable elements** (callouts, key UI features)

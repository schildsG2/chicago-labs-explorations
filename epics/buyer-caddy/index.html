Tech Stack Table — States & Edge Cases 6 states · Based on Layout B Flat Table · Informed by Figma explorations

State 1 · Pre-unlock
Null — No Data
BuyerCaddy returned no tech stack results for this company. No unlock button — there is nothing to unlock. Empty state with explanation.
No products detected · No CTA
→
State 2 · Transitional
Loading — Unlock in Progress
User clicked Unlock. Credits deducted. API call in flight. Skeleton table rows + spinner convey that data is on the way without blocking the rest of the page.
Skeleton rows · Spinner · Disabled CTA
→
State 3 · Transitional
Refreshing — Re-fetch in Progress
Previously unlocked. User clicked Refresh Stack. Existing data stays visible but dimmed — a floating pill overlay signals the update without fully blocking content.
Existing data visible · Non-blocking overlay
→
State 4 · Post-unlock
Stale — Data Older than 6 Months
Stack was unlocked and data is still showing, but last verified dates are aging past reliability threshold. Amber warning banner nudges user to refresh before generating emails.
Amber banner · Stale date highlight · Refresh CTA
→
State 5 · Failure
Error — Fetch Failed
API call failed mid-unlock or mid-refresh. Credits were not charged. Error state with retry CTA and explicit note that no credits were deducted.
Error UI · No credits deducted · Retry CTA
→
State 6 · Pre-unlock
Insufficient Credits
Locked state variant where the user's credit balance is below the cost to unlock. Button is disabled. Overlay callout surfaces balance vs. cost with a credit progress bar and upgrade path.
Disabled unlock · Credit balance · Upgrade CTA

Usage Notes

  • Purpose — Small utility buttons for UI controls, not primary actions
  • Always include aria-label — control buttons need accessible labels
  • Close variant — Use --close modifier for destructive close actions (red hover)
  • Subtle styling — Transparent background, hover reveals light gray
  • Focus states — 2px purple outline for keyboard accessibility
  • Common icons — close, menu, expand_more, expand_less, fullscreen, minimize, more_vert
  • Positioning — Typically positioned at panel edges or in headers

# AGENTS.md

> Compact context for AI agents working in this repo. Every line answers: "Would an agent miss this without help?"

## What This Repo Is

Static HTML prototyping workspace for G2 product design explorations. **Zero build tools** — open any `.html` file directly in a browser. No bundler, no framework, no package.json, no test runner.

## Authoritative Sources (read order)

1. **`CLAUDE.md`** (root) — Full agent context, design system rules, workflow conventions
2. **`shared/elevate-prototyping-kit/design-system/DESIGN.md`** — The authoritative Elevate spec. Read the relevant section BEFORE generating any UI.
3. **Epic-level `CLAUDE.md`** — 7 epics have their own context files in `epics/{name}/CLAUDE.md`

`CLAUDE.md` is comprehensive. This file covers only what it doesn't.

## Submodule

`shared/elevate-prototyping-kit/` is an active **git submodule** (→ `schildsG2/elevate-prototyping-kit.git`). After cloning:

```bash
git submodule update --init --recursive
```

If `shared/elevate-prototyping-kit/` is empty, that's why.

> **Note:** `shared/elevate-lite/` also exists, but as **frozen regular files** (not a submodule). Old explorations under `epics/*/` reference it and work without any submodule initialization. Do not edit files there.

## CSS Architecture (4 files, always)

New explorations load these four CSS files via relative paths from `shared/elevate-prototyping-kit/`:

```html
<link rel="stylesheet" href="../../shared/elevate-prototyping-kit/tokens/elevate.css">
<link rel="stylesheet" href="../../shared/elevate-prototyping-kit/components/elevate.css">
<link rel="stylesheet" href="../../shared/elevate-prototyping-kit/utilities.css">
<link rel="stylesheet" href="../../shared/elevate-prototyping-kit/icons/icons.css">
```

- Path depth depends on file location: `../../` from `epics/{name}/explorations/`, `../` from `epics/{name}/`
- `elevate.css` (tokens) — 300+ CSS custom properties
- `elevate.css` (components) — Component classes (buttons, chips, forms). This is a **static copy** of UE production Elevate CSS, not auto-synced.
- `icons.css` — 293 SVG icons

## Conventions That Differ From Defaults

- **Utility prefix**: `elv-` (e.g., `elv-flex`, `elv-p-4`, `elv-text-default`). Not Tailwind — these are Elevate utilities.
- **Component classes**: BEM-like with no prefix (e.g., `btn btn--primary btn--md`)
- **Never pure black**: Always use `text-default` (#201f23) — never `#000000`
- **Only Figtree font** — no secondary typefaces
- **4px spacing base** — all spacing values are multiples of 4
- **Rorange (#ff492c)**: Brand only. Never for sentiment, data viz, or eyebrows.
- **Purple (#5746b2)**: Primary CTAs and brand identity.

## File & Directory Patterns

- Explorations: `epics/{epic-name}/explorations/##-descriptive-name.html` (zero-padded number preserves chronology)
- Epic gallery: `epics/{epic-name}/index.html` (links to all explorations within that epic)
- Root portal: `index.html` (filterable gallery of all epics + research)
- Starter template: `shared/exploration-starter.html` — copy this for new explorations
- Research spikes: `research/spikes/{name}.md` or `.html`

## Adding a New Epic

Use the `.claude/skills/new-epic.skill` if available. Otherwise:

1. Create `epics/{epic-name}/` with `explorations/` subdirectory and `index.html`
2. Copy gallery structure from `epics/design-exploration-example/index.html`
3. Add an epic card to root `index.html` inside `#epicGrid`
4. Update the epic count in `#epicCount`
5. If adding a new tag, also add a filter chip to the controls section

## Common Mistakes to Avoid

- Inventing colors, spacing, or components not in DESIGN.md or `elevate.css`
- Using Tailwind class names instead of `elv-` prefixed utilities
- Forgetting the `elv` attribute on the root container (`<div elv>`)
- Getting CSS relative paths wrong when nesting files deeper than expected
- Treating `shared-backup/` as the live design system (it's stale)
- Editing files inside `shared/elevate-lite/` (frozen legacy files — leave them alone)
- Using `shared/elevate-lite/` paths in new explorations (use `shared/elevate-prototyping-kit/` instead)
